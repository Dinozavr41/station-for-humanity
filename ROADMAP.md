# Station for Humanity — Roadmap

This roadmap prioritizes proving the smallest complete value loop before attempting global scale.

## Alpha 0.1 — Public foundation — DONE

- register `stationforhumanity.com`;
- deploy first public site;
- publish Article 0;
- create public GitHub repository;
- connect GitHub → Vercel → production domain;
- record the founding log.

## Alpha 0.2 — Social entry layer — CURRENT

- five-role Join the Station interface;
- local Founding Ticket prototype;
- public Dream #000001 — PILOT;
- public Value Ledger concept;
- public social contract architecture;
- Constitution Draft 0.2;
- canonical project memory;
- zero-based honest public metrics.

## Alpha 0.3 — Real intake backend

Goal: a person can submit a real task or contribution and receive a persistent station identifier.

Candidate scope:

- backend API;
- database;
- basic identity / session model;
- consent and privacy controls;
- spam / abuse prevention;
- role and Founding Ticket persistence;
- admin review queue;
- public / private field separation.

## Alpha 0.4 — Digital Factory MVP

Goal: accept one narrow category of real commercial work from intake to delivery.

First product should be selected by:

- strong automation potential;
- clear customer value;
- low fulfillment ambiguity;
- low regulatory burden;
- fast QA;
- ability to price competitively.

Required loop:

`lead → intake → specification → price → payment → production → QA → delivery`

## Alpha 0.5 — Value Ledger MVP

Goal: the first real order creates the first auditable value event.

Record:

- order value;
- direct costs;
- human contribution;
- module contribution;
- infrastructure contribution;
- approved revenue allocations;
- delivery evidence;
- social / dream allocation if applicable.

## Alpha 0.6 — First external contributor

Goal: someone outside the founding build contributes useful work or a reusable module and receives a legitimate recorded reward.

## Alpha 0.7 — First dream movement

Goal: Dream #000001 moves from 0% using real station-created value, with public evidence of the milestone but without exposing unnecessary sensitive data.

## Beta — Module economy

- module registry;
- module interfaces and permissions;
- versioning;
- usage metering;
- royalty attribution;
- QA / trust score;
- dispute handling;
- developer documentation.

## Later — Dream Commons

- verified dreams;
- decomposition into needs;
- matching money, skills, equipment, discounts, logistics and knowledge;
- milestone execution;
- impact verification.

## Later — Social dividend and governance

Only after sustainable unit economics and legal review:

- builder / pension mechanisms;
- opportunity and emergency mechanisms;
- automation dividend;
- representative governance;
- independent audit;
- federation of regional / professional nodes.

## Long horizon — Dream Station

A federated global value network in which many independent people, communities, companies, AI systems and machines can dock useful capabilities without any one participant needing to build the whole system.
